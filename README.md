# CodeCartia（源图）

面向开发者的本地跨语言代码理解与架构探索工具。目标是将跨文件、跨工程和跨语言的源码关系绘成可探索的地图，帮助开发者理解业务链路、查看源码依据和判断修改影响。

**当前处于设计阶段。** 仓库已收录设计方案 v0.3 及审查报告的复核与修订记录，尚未实现 CLI、Web 界面、分析器或规则迭代功能，也没有可安装的发布包。下列内容是已确认的产品目标，实际支持范围将在实现与验收后公布。

## 产品目标

- 采用 **CLI＋本地 Web 界面**，管理一个或多个工程，提供系统总览、模块与文件、业务流程、符号与调用视图。
- 以静态分析建立关系，每条确认关系保留源码或明确元数据依据；动态行为保留候选、条件和未解析状态。
- 关联前端请求与后端端点，并分析 WebSocket、进程、文件及常见 FFI 边界。
- AI 可选用于解释已有证据、辅助识别及归纳改进规则；核心静态功能的设计不依赖 AI。
- 首版包含跨项目改进闭环：**发现错连或漏连 → AI 提出候选规则 → 源码与语义核对 → 独立项目验证 → 回归测试 → 版本化固化与回滚**。

## 首版目标范围

| 工程类别 | 目标语言与框架 |
|---|---|
| 前端 | 原生 JavaScript、Vue、React，以及常用的 TypeScript、JSX、TSX、HTML 与配置文件 |
| 后端与全栈 | Java、C#、Node.js、Next.js、C、C++、Python；Next.js 按全栈框架分析 |

**首版所有目标语言同步达到深度分析要求。** 内部可以并行实现，但首版发布以各适配器分别通过验收为前提；仅完成语法索引不能计为深度分析完成。框架版本、编译上下文与具体验收口径详见设计方案。
