# 示例工程

本目录存放用于理解 CodeCartia 目标阅读体验的合成工程。

| 目录 | 用途与状态 |
|---|---|
| [purchase-demo](purchase-demo/README.md) | 原生 JavaScript 前后端采购示例，可运行三类动作与公开功能测试；HTML 体验原型嵌入其真实源码，关系与场景结果仍为模拟数据 |
| [prototypes](prototypes/README.md) | M1-04 隔离实验初稿：JS/TS、Python 与 C#；输入/独立预期已准备，最终运行验证未完成，环境见 [盘点](../docs/progress/M1-04-环境盘点.md) |

示例不代表 CodeCartia 分析器已实现，不是完整 BS/AP 可执行基准或独立保留测试集。首版所有目标语言的深度分析与跨项目改进验收要求保持不变。
