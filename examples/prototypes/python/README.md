# Python AST 局部事实实验

本目录为 M1-04 的隔离实验，正在准备可复现输入与独立对照；不是产品分析器、完整统一 schema 或 worker 实现。探索工具使用本机已安装的 Python 3.14.2 标准库 `ast`，不冻结 Python、类型辅助工具或框架版本。

实验只读取 `inputs.json` 登记的 `fixtures/` 原始源码，不导入或执行这些模块。源码与 `expected/` 预期分开；预期仅供验证器使用，不作为提取器输入。目录内实现采用通用的模块、函数、词法作用域与调用表达式，不固定任何业务模型。

句法事实、受限模式下的声明引用绑定与运行时调用目标分别记录。缺输入、赋值重绑、动态属性、猴子补丁、装饰器和未验证类型信息保留未知或边界诊断。AST 扫描完整不等于 Python 深度分析、类型辅助、框架分析或产品验收完成。

完成执行后在本页登记实际命令、产物和限制；统一契约与 worker 边界见 [契约入口](../../../docs/contracts/README.md)，目标范围见 [语言清单](../../../docs/capabilities/M1-语言框架与输入覆盖清单.md)。
