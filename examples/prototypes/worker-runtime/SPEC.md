# 进程、消息与持久化验证规格

版本：runtime-experiment-v0.1；日期：2026-11-12。先定义下列预期，再实现与执行。预期来自已交付的 M1-03 独立 W-* 规格及 D12；测试生产者不是语言提取器。

## 探索实现与边界

- 独立 Python 受控 worker，UTF-8 JSONL 协议流与独立 stderr 日志。原始接收帧、顺序、裁决和进程退出分别记录。
- protocolVersion 与 schemaVersion 均精确选择 0.2-draft；bootstrap 保持 codecartia-worker-bootstrap-v0.1-draft。
- JSON 摘要采用 UTF-8、排序对象键、不转义 Unicode、紧凑分隔、拒绝非有限数值；批次摘要覆盖除 payloadFingerprint 外的整个 payload。数组不排序。
- 每会话最多一个活动 attempt；事实额度和控制处理分开，初始事实额度可以为零。未声明的跨 worker 外部依赖、主题记录/扩展不冒充支持。
- 接收器核对公共 FactRef、独立推导、来源、批次/终结清单及完整性子集；不宣称完整主题 schema、身份连续性、语义正确性或多 worker 组合已验证。
- SQLite 使用显式 BEGIN IMMEDIATE 事务、WAL、synchronous=FULL。最新请求登记与最终发布分别持久化；最终事务内再次比较最新世代和活动 attempt。
- 本实验只验证进程异常退出后的数据库可恢复性，不把杀进程等同真实断电、磁盘损坏或所有操作系统行为。

## 独立预期

| 验证组 | 来源 | 指定操作 | 必须观察 |
|---|---|---|---|
| 协商 | W-H、WP01/02 | 无共同 schema、未知必要特性、必要模式不支持 | 拒绝会话或请求；不开始产出，不改其他任务 |
| 包络 | W-M、WP03 | 错会话/attempt、冻结请求字段变化 | 隔离错身份消息；匹配的协议错误使本 attempt 失败 |
| 批次 | W-B、WP04/05/06 | 前向引用、重复重发、不同批次重复记录、缺批/错计数/错摘要 | ACK 仅暂存；精确去重且原始计数正确；错误不得完成 |
| 事实 | W-B、WP11/15 | 错 revision、ID-only、自支持、辅助来源伪自动 | 拒绝精确引用缺口、环和来源污染；不回退到同 ID 最新记录 |
| 控制 | W-L、WP07/08/10 | 零事实额度取消、取消先赢、完成先赢、finished 已到但未校验 | 宿主裁决不逆转；ACK 与实际进程停止分别记录 |
| 故障 | W-L、WP08/09 | worker EOF/崩溃、无响应、超期限 | 有界封存/清理，本进程被回收，旧 current 保留 |
| 部分输出 | W-S01/09、WP13 | 合法 partial 配 allowPartial true/false | 分别 sealed_partial 或 semantic_incomplete；协议完整性不被混淆，均不替换完整快照 |
| 发布世代 | W-L10/11/12、D12 | A/B 乱序、最新 B 失败、A 预检后才登记 B、同请求重发/失败重试 | 最新世代不回退；A 只保留历史；重发不增世代，旧 attempt 不复活 |
| 持久化 | WP14/16、R12 | 真实子进程在事务提交前/后被终止，重开数据库 | 提交前全部回滚，提交后完整保存；最新登记请求与 current 一致恢复 |
| 来源日志 | WP10 | stderr 写看似 facts.batch 的 JSON | 日志仅日志，不进入事实账本 |

报告包含测试输入/源码/配置指纹、环境、探索上限、原始消息与独立断言、退出/清理和存储观察。测试数只表示上述指定用例，不是质量百分比或 G1 完成率。
