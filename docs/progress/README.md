2026-11-12 范围修订按用户确认的 [D13](../decisions/D13-初版语言验证范围.md)：初版只验证 JS/TS（含原生 JS、Vue/React/Node/Next、JSX/TSX、HTML 与配置）及 Python；Java、C#、C、C++ 及其专属框架/工具链整体延后，不阻塞初版 M1/G1、M3/G3、M6/G6，不计为通过。既有 C# 实验和环境预览保留历史，Ubuntu/Docker 多语言准备改为后续可选，本次不安装；完整范围见[设计方案 §5](../CodeCartia-设计方案.md)。
