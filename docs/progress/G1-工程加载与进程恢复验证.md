## 3. 关键行为与复核

- 原始输入和独立预期分开；提取器只读取源码、配置与显式允许的语义输入。输入树与执行哨兵对照用于核对副作用，不能只看提取器自报“没有执行”。
- JS/TS 相同源文件在不同配置中保留各自绑定；扫描完成不意味着调用目标完整。Python 的词法声明、动态运行目标、可达性与类型分别表达，后置局部重绑不能借用外层同名声明。
- 用户提供 platform-server 后发现无扩展名 Node 入口被默认后缀扫描遗漏，新增通用 additionalEntryFiles 技术登记：入口实际按 JavaScript 纳入主配置并参与符号/调用分析，路径、语言、shebang、读取和预算可复核。没有硬编码项目路径或业务词，也没有执行启动脚本；CommonJS require 的独立导入关系及框架语义仍未扩展。
- 原始字节指纹与源码范围逐项核对；跨文件目标必须对应真实声明。评估器需拒绝空输出、额外/遗漏调用、同文件换错目标、配置串线、unknown 升级及过期报告。
- 映射复核补入相同声明跨配置串线及必需语义输入遗漏：即使错误推导重算了合法 revision、来源闭包及支持索引，缺少必要 source/target EntityVersion 或原始 Evidence 仍被拒绝。位置采用源报告实际保留的字节坐标，不伪造已丢失的 Compiler/AST 原生位置。
- 项目读取与报告写入检查路径、现存链接及输入覆盖；交叉审查增加硬链接输出保护。Windows 文件符号链接创建权限不足的用例单独标记跳过；目录 junction 的实际拒绝不能替代这一未执行变体。并发替换路径与其他系统仍未证明。
- worker ACK 只确认暂存；finished 到达后仍须核对清单、精确 FactRef、来源和完整性。取消在校验窗口获接受后，后到 finished 不逆转宿主裁决；取消 ACK 与真正进程退出分别记录。
- 复核补入 Python 推导式海象赋值、global/nonlocal 的声明/导入共享写入、模块字典写入/删除对引用的失效反例；未受影响的正例仍可确认。worker 的持续错身份帧不能拖过绝对期限，所有帧计入会话额度；非有限 JSON 数值、孤立 surrogate、过深嵌套与缺必需字段统一作为协议错误封存。会话额度反例精确命中总帧上限，不借队列溢出代替。
- 持久化实验在真实 SQLite 事务提交前、提交后各终止一个受控子进程并重开数据库。最新请求登记不回退，旧请求仅保留历史；发布失败不逆转 sealed_completed 的执行裁决。该结果只证明所测进程故障模型，不外推为断电/磁盘损坏验证。

当前 Node/TypeScript、Python/SQLite 均复用本机已有环境；未安装或下载新依赖。探索上限的含义和未覆盖项见[工程加载模式与预算](../capabilities/M1-工程加载实验模式与预算.md)。

分工为主代理实现公共进程/持久化及整合，两条语言代理负责各自提取器和相互审查，质量代理先写独立工程预期并复核实际结果。质量复核另核对了最新 runtime 报告的源码指纹、800 条原始帧的字节/摘要/解码一致性及 58 个 worker 的退出记录。

本批首次 Python 开发测试使用 tempfile 的限制权限目录，在 Windows 沙箱内首个文件写入即失败。测试改用 reports 内继承权限的 UUID 目录后通过。早先两次清理因自动审批服务的 content-blocked 错误未执行；用户随后明确批准仅修复该临时目录。首次通用 Set-Acl 遇到 SeSecurityPrivilege 限制，改为只复制父目录的访问 DACL（不设置所有者/审计项），成功读取并确认目录为空，再非递归删除。路径和父链均已核对无重解析点；`.project-probe-jasfmd7d` 清理已完成，未处理其他目录。
