## 3. 交叉复核问题与处理

两位作者互相核对，`worker_review` 与主代理分别回到设计、任务与四份 M1-02 源契约复核，不以文档作者自检替代独立结论。修订稿已完成独立内容核对，文档交叉复核通过；以下记录实际发现、修订及关闭状态。

| 发现 / 复核来源 | 修订 | 状态 |
|---|---|---|
| `allowPartial=false` 与正常部分结果终态未对应 / 主代理、质量复核代理 | 提前已知必要缺口拒绝任务；运行后缺口区分 protocolIntegrity=valid 与 semanticCompleteness=incomplete，封存语义失败并保留隔离局部材料 | 已关闭并独立复核 |
| 合法记录版本/独立推导可能被当载荷冲突 / 主代理 | 明确 wireRecordKey；同键异内容才完整性冲突，不同版本/独立 Derivation 按 R07 处理；载荷出现计数与物化唯一计数分开 | 已关闭并独立复核 |
| worker 的取消 ACK 被用于宿主裁决 / 主代理、预期作者 | 增加 HostCancelResult；worker cancel.ack 只表示自身观察，宿主已封存完成可本地返回 already_terminal | 已关闭并独立复核 |
| 封存完成后发布失败可能逆转唯一终态 / 主代理 | open 时校验/输入失败封存 failed；sealed_completed 后发布前输入或事务失败仅撤销 publication eligibility，执行裁决保留、发布结果隔离 | 已关闭并独立复核 |
| 冻结内容篡改与旧尝试迟到消息混为一类 / 主代理 | 旧/外来隔离键只审计；命中当前键但冻结内容违约使当前 attempt 协议失败，不影响无关任务 | 已关闭并独立复核 |
| 跨 worker 引用可能无限等待或隐式拼旧边 / 作者、质量复核代理 | declaredExternalProviders 明确同快照提供者；waiting_external_refs 有期限和失败依赖 scope；未定义差量编码不隐式保留旧输出 | 已关闭并独立复核 |
| 接收取消受背压阻塞、强杀同进程其他任务仍显示运行 / 主代理、质量复核代理 | 控制与事实额度分开；控制故障独立记录。进程级清理标明同进程全部未封存任务影响，不把任务级停止能力当默认 | 已关闭并独立复核 |
| task.rejected 后宿主可能等待不存在的 finished / 质量复核代理 | 已登记匹配请求立即封存 request_rejected；引导拒绝不造任务，缺定位键通过会话错误关联消息 | 已关闭并独立复核 |

批次 ACK、worker finished、宿主执行裁决与原子发布分别表达；先角色后场景及有语义顺序只由原始字段与规则决定。源码、配置、AI/人工和运行观察来源保持隔离，受控消息不替代自动分析结果。主协议、正反例与报告要求均明确尚未执行。
