## 2. 已确认的开发环境方案

用户明确选择：**Docker Engine＋Compose，语言工具放入固定镜像**。范围是复用现有 Ubuntu 虚拟机作为 M1 开发/实验环境，尚不授权执行安装，也不把 Docker 设为产品用户必装条件。

- Windows 继续保留编辑器、仓库及现有可用工具。
- Ubuntu 中准备容器运行环境；安装前先核对已有软件包、仓库、架构和服务，避免依据 PATH 结果直接重复安装。
- 语言 SDK、编译器及依赖在实验镜像中准备；具体版本、内容指纹/镜像摘要及输入映射须登记后验证，不使用浮动标签冒充固定环境。
- 先启动小规模、有限并发实验，再按耗时/内存/磁盘测量调整。当前不建议仅因工具种类多就升级虚拟机资源。
- 源码/语义输入与缓存/报告分别处理，遵守只读取证边界；Windows SDK/MSVC及 Windows 特有路径/进程行为仍有独立验证线。

Docker Engine＋Compose 是否实际可用、镜像获取、网络及各语言分析均尚未验证。开发容器的 Linux 空间也不能被当成被分析应用的实际运行空间。

## 3. 安装前尚需取得的依据

1. 官方 Ubuntu 安装步骤及仓库/组件要求，现有软件包与安装源状态。
2. 可审阅的安装动作、所需权限、服务及用户访问方式；任何系统变更在明确授权后执行。
3. 各 SDK/基础镜像实际版本及摘要、平台与依赖兼容，后续原始输入/独立预期/真实结果。
