# 架构与设计图解

本目录提供 CodeCartia 的离线 HTML 图解，按产品全景、系统架构、分析流程、核心模型、业务示例、界面导航、快照变化和规则改进组织八个章节。

每章提供“一句话看懂”、读图方法、小例子和图的对象说明；全部节点都有通俗解释。点击节点先看通俗解释，再查专业说明与依据，也可展开本章节点列表阅读或定位。第二章说明 CodeCartia 自身的规划架构，第五章说明合成采购示例的业务条件。

依据为设计方案 v0.6、推进方案 v0.4 和验收样例 v0.3。图中描述的是设计，技术选型仍待验证；图解页面可阅读不代表 CLI、Web 产品、分析器或验收样例已经实现。

## 阅读入口

- [交互图解成品：index.html](index.html)：用 Chrome 等浏览器直接打开，支持章节跳转、缩放、平移、节点详情和合成界面示例，无需网络或安装依赖。误打开编辑模板时会提示并跳转到此页面。
- [Markdown 图解](architecture-guide.md)：同步提供八章通俗说明、节点解释表、设计依据和 Mermaid 图源。打印图集也包含各章说明页；独立 SVG 的节点悬停提示保留通俗解释。
- [产品体验原型](../prototype/index.html)：用模拟结果探索采购场景、步骤授权和真实示例源码。
- [完整设计](../CodeCartia-设计方案.md)：范围、模型与契约的详细依据。

## 实际文件

```text
diagrams/
├─ index.html               # 生成的离线交互阅读页面
├─ architecture-guide.md    # 生成的 Markdown 图解
├─ graph-specs.json         # 图内容、布局、来源及 Mermaid 源码
├─ viewer-template.html     # 编辑模板；直接打开时跳转到 index.html
├─ build.py                 # 标准库生成脚本及结构校验
├─ svgs/                    # 八张独立 SVG，可在页面中下载
├─ sources/                 # 八份 Mermaid 图源
└─ README.md                # 阅读与维护说明
```

## 维护与自定义

1. 修改图的说明、节点、连线、布局和来源时编辑 `graph-specs.json`，同时保持其中 Mermaid 与结构化图的语义一致。每图的 `plainGuide` 保存 `summary`（一句话）、`reading`（读图方法列表）、`example`（小例子）、`scope`（图的对象和设计状态）；每个节点的 `plainExplanation` 保存通俗解释，`detail` 保留专业说明。
2. 修改页面布局、配色和交互时编辑 `viewer-template.html`。模板中的两个数据标记由生成脚本替换，阅读成品为 `index.html`；模板自身不包含图数据。
3. 在项目根目录执行 `python docs/diagrams/build.py`；需要 Python 3.9 或更高版本，仅使用标准库，不安装前端依赖。
4. 生成脚本检查八章及全部节点的通俗说明覆盖、节点身份、画布边界、文字高度、节点重叠、连线引用和来源路径，并让连线标签避开节点与其他标签；修改后仍须在浏览器中检查实际效果。

图解不另行决定产品范围或技术选型。设计发生变化时先核对相关设计、验收与决策文档，再同步图源和生成产物。本图解的 `F.*` 按合成规格定位，产品体验原型另将部分标签映射到真实示例源码；页面的角色筛选仅改变阅读范围。
