# M1 统一契约草案

本目录用于 M1-02「统一契约草案」的文档交付，依据设计 v0.6、推进 v0.4 与 M1-01 清单。四份 0.1 草案已交付并通过文档交叉复核；尚无冻结契约、worker 协议实现、各语言真实分析输出或契约执行报告。M1-02 工作包仍进行中，跨语言事实核对与可执行验证待后续工作包。

契约以跨项目通用事实为输入，以业务场景、步骤/动作、对象与规则组织结果，在步骤内绑定参与者和授权；角色反查使用同一关系。示例名称、角色、路径及数值仅为指定输入，不作为产品默认规则。

按以下顺序阅读，先看最小正反例再核对字段与约束。各主题共用 `schemaVersion=0.1-draft`；草案中的字段拼写与枚举是供下游原型核对的提议，未选择序列化实现、工具链版本、预算或质量门槛。

| 文档 | 内容与边界 |
|---|---|
| [统一图与证据](M1-统一图与证据契约.md) | 身份/版本、公共引用、条件、解析与完整性、原始坐标/映射、逐项证据与来源隔离 |
| [调用上下文与 HTTP 分发](M1-调用上下文与HTTP分发契约.md) | 实参/返回配对、路径相容、地址候选、有序可达处理链及检查覆盖 |
| [资源、快照与规则组合](M1-资源快照与规则组合契约.md) | 输入/展示边界、空间/挂载/broker、查询与集合、原子发布、增量等价、合并/覆盖/回退 |
| [业务场景与步骤授权](M1-业务场景与步骤授权契约.md) | 场景/对象/状态、身份与角色、多对多步骤绑定、未关联诊断、顺序/身份确定结果及同关系反查 |

交付和复核结果见 [M1-02 复核记录](../progress/M1-02-复核记录.md)。正反例是待执行规格，坐标示例及策略/身份结果是手工推演，不代表自动分析成绩。下一步可据此编写 M1-03 worker 协议草案；M1-04/07 再反馈真实事实和执行结果，M1-09 汇总后才冻结。
