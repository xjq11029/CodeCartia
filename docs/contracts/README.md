# M1 统一契约与 worker 协议草案

本目录用于 M1-02「统一契约草案」与 M1-03「worker 与扩展协议」的文档交付，依据设计 v0.6、推进 v0.4 与 M1-01 清单。M1-02 四份 0.1 草案已通过文档交叉复核；M1-03 主协议及独立正反例/实验规格已交付并通过文档交叉复核。尚无冻结契约、worker 协议实现、各语言真实分析输出或契约执行报告，M1-02/03 工作包仍进行中。

契约以跨项目通用事实为输入，以业务场景、步骤/动作、对象与规则组织结果，在步骤内绑定参与者和授权；角色反查使用同一关系。示例名称、角色、路径及数值仅为指定输入，不作为产品默认规则。

按以下顺序阅读，先看最小正反例再核对字段与约束。事实模型共用 `schemaVersion=0.1-draft`，worker 控制消息独立使用 `protocolVersion=0.1-draft`；相同版本号不代表含义或兼容性相同。草案中的字段拼写与枚举是供下游原型核对的提议，未选择序列化实现、工具链版本、预算或质量门槛。

| [调用上下文与 HTTP 分发](M1-调用上下文与HTTP分发契约.md) | 实参/返回配对、路径相容、地址候选、有序可达处理链及检查覆盖 |
